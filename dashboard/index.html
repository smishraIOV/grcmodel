What-if: a firm under a policy

Enter a firm and what it does; see what the next period, a set of stresses and the next few years could hold. The assumptions are illustrative, not calibrated: read shapes, not levels. Nothing here searches for the best policy.

How these figures are worked out

Every figure is recalculated from your inputs each time you change one. It makes no difference whether you change the policy, the firm's facts or an assumption: the whole page is worked out again, from nothing. Nothing is remembered between changes.

There is no AI model behind this page. No neural network, and nothing trained or learned. The figures come from accounting rules written out in code: how loans are made and liquidated, how fees and investors' money flow, and what that does to the firm's books. A numerical library (PyTorch) does the arithmetic quickly; it is used here as a calculator, not as a model.

The page uses three kinds of calculation:

What you seeHow it is worked outAny randomness?
One period ahead, and the first three headline figures An average over a fixed set of weighted scenariosNone
Under stressOne outcome for each scenario, worked through directlyNone
Over the years, and the last three headline figures 20,000 simulated paths, run again on every changeYes, but the same random draws every time

The simulation uses the same random draws on every run. So when a figure moves after you change an input, it moved because of the input and not because of different luck. The one exception: changing the number of years, or how often the firm decides, needs a different number of draws, so those runs use a different set of paths. Figures from the paths carry sampling error, which is shown where it matters.

"What does this lean on?" is worked out only when you ask. It repeats the whole calculation about 27 times (twice that with a second policy), so it takes around 15 seconds, and it is marked as out of date once an input changes.

Nothing leaves this machine. The calculation runs in the program you started; the page loads nothing from the internet, and a firm is kept only in a file you save.
